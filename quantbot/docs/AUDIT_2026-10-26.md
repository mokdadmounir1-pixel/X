## Demandes du cahier des charges : état réel
| Demande | État | Raison |
|---|---|---|
| **3 € net par trade : 1 lot, TP 0,03 $, SL 0,02 $, time-stop 10 s** | **IMPOSSIBLE sur ce flux** | Spread médian mesuré sur l'or : **0,08 $** (25 % : 0,05 ; 75 % : 0,14). Il ne descend à ≤ 0,03 $ que **0,34 %** du temps. Le coût d'un aller-retour dépasse donc le TP : même avec 100 % de réussite le trade est perdant. Avec spread nul le taux d'équilibre est 40 % ; à 0,02 $ de spread il monte à 80 % ; à 0,03 $ il n'existe pas. Seul un compte à spread brut très bas (ECN) avec commission fixe pourrait s'en approcher : à MESURER (tâche C3), pas à supposer. |
| ≥ 7 % net / mois | Non promettable | 106 essais préenregistrés, 0 PASS ; meilleur résultat honnête ≈ +0,03 à +0,09 R/jour. Un chiffre garanti serait un résultat truqué. |
| Circuit breaker 1,5 %/jour | Fait | `risk/active.py` (`daily_loss_halt`, réalisé + latent, désactivé par défaut) + `live/killswitch.py` ; à ACTIVER dans la spec de démo. |
| Exécution < 10 ms sur VPS LD4/NY4 | Non atteignable avec cette pile | L'API Python de MT5 est un appel inter-processus vers le terminal (typiquement des dizaines de ms, mesure à faire grâce au journal `executions`). Le moteur décide à la clôture de barre (M15), il n'est pas un moteur HFT. Un vrai HFT demande une autre pile (C++/FIX, co-location, carnet). |
| Séparer moteur d'exécution et interface | Déjà séparé, plus strictement que demandé | L'interface (FastAPI, lecture seule) est un autre processus qui lit des fichiers/SQLite ; elle ne peut pas bloquer le trading. Pas de réécriture PyQt6 : aucun gain. |
| asyncio + files + signaux PyQt6 | Non fait volontairement | L'API MT5 est bloquante ; l'envelopper en asyncio n'enlève aucune latence. |
| Micro-prix, toxicité VPIN | Fonctions faites (`order_flow_ofi.py`) | Exigent de vraies tailles bid/ask (micro-prix) et un ruban de transactions (VPIN). Aujourd'hui : proxys nommés comme tels. Données de carnet : collecte automatique de la profondeur XAUUSD si le courtier l'expose. |
| Détection d'icebergs, murs passifs | Proxy d'absorption seulement | Un iceberg est invisible par construction ; sans L2/L3 réels on ne peut pas le détecter. |
| Fade des faux breakouts avec Volume Delta | Non faisable | Pas de volume delta dans les exports MT5 CFD. |
| Reconnexion WebSocket avec backoff | Partiel | MT5 : pas de WebSocket (réinitialisation par le démon). Coinbase : REST avec relances à backoff exponentiel. Un WebSocket Coinbase n'est pas écrit. |
| Journal d'audit append-only | Fait (point 4) | idem |
